# 0011. AGPL-3.0 license

- Status: Accepted
- Date: 2025-11-27
- Commits: 41c41a2, 19f1f3d

## Context
The project uses Ultralytics YOLO, which is licensed under AGPL-3.0, and ships fine-tuned YOLO weights.

## Decision
The project itself is licensed under AGPL-3.0 (changed in 19f1f3d).

## Consequences
- Compatible with Ultralytics without a commercial license.
- Anyone who offers a modified version over a network has to publish their source code.
